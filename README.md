# Authentication-Secrets

Run `npm ci` with Node.js 24. Set `CLIENT_ID`, `CLIENT_SECRET`, and `SESSION_SECRET`, then run `node app.js`.

Set `MONGODB_URI` to use a configured database. The local default is `mongodb://127.0.0.1:27017/userDB`. Set `OAUTH_CALLBACK_URL` to the callback registered with Google when hosting the app.
